# Devin Todo

A tiny Todo web application built to learn the Devin development workflow.

## Scope

This is a deliberately simple, client-side-only Todo app:

- Create todos
- Mark todos as completed
- Edit todo text
- Delete todos
- Filter by All / Active / Completed
- Persist todos to `localStorage`

No backend, authentication, or database in v1.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vitest + React Testing Library

## Development Commands

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Type check
npm run type-check

# Run tests
npm test
```
